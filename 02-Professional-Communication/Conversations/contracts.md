### Scope Creep
- **Pronunciation**: "SKOHP kreep" · سكوب كريب
- **Arabic**: زحف النطاق (زيادة المتطلبات باستمرار)
- **Definition**: The uncontrolled or continuous growth in a project's scope (features, requirements) after the project has begun, usually without corresponding increases in budget or time.
- **Context**: Freelance projects, fixed-price contracts, agile sprint planning.
- **Usage Examples**:
  - *Formal*: "To mitigate scope creep, we must document all requested changes and issue a formal change order with an updated budget."
  - *Casual*: "The client just asked for three more screens — major scope creep. We need to push back."
- **Common Mistake**: Failing to define the initial scope clearly in writing, leaving the door open for endless "small" additions.
- **Related Terms**: Deliverable, Fixed-Price, Change Order

### Fixed-Price vs Hourly
- **Pronunciation**: "FIXED-prys vs OUR-lee" · فيكسد برايس / أورلي
- **Arabic**: السعر الثابت مقابل الدفع بالساعة
- **Definition**: Two primary billing models. *Fixed-price* pays a set amount for a defined deliverable regardless of time spent. *Hourly* pays for the actual time worked, which is better for projects with vague or changing requirements.
- **Context**: Upwork proposals, contract negotiation, client onboarding.
- **Usage Examples**:
  - *Formal*: "Given the undefined nature of the third-party API integration, I recommend an hourly contract rather than a fixed-price arrangement."
  - *Casual*: "I don't do fixed-price for bug fixes because I have no idea how deep the rabbit hole goes."
- **Common Mistake**: Accepting a fixed-price contract on a project with unclear requirements, practically guaranteeing you will work for a terrible hourly rate.
- **Related Terms**: Retainer, Scope Creep, Estimate

### NDA (Non-Disclosure Agreement)
- **Pronunciation**: "en-dee-AY" · إن دي إيه
- **Arabic**: اتفاقية عدم الإفصاح / سرية المعلومات
- **Definition**: A legal contract establishing a confidential relationship. The person signing agrees not to share sensitive information, trade secrets, or proprietary code they encounter during the project.
- **Context**: Onboarding new clients, discussing portfolio pieces, enterprise software.
- **Usage Examples**:
  - *Formal*: "I cannot share the source code for the healthcare SaaS platform, as that intellectual property is protected by a strict NDA."
  - *Casual*: "Can't show you that repo, it's under NDA."
- **Common Mistake**: Breaking an NDA by posting proprietary client code on your public GitHub or explaining sensitive business logic in an interview.
- **Related Terms**: Proprietary, Intellectual Property, Compliance
