# Phrasal Verbs for Tech Contexts

Phrasal verbs are combinations of a verb + preposition/adverb that create a new meaning. They're extremely common in spoken English and casual professional communication.

---

### "Follow up (on)"
- **Pronunciation**: "FOL-oh up" · فولو أب
- **Arabic**: متابعة
- **Meaning**: To check on the status of something previously discussed or requested.
- **Usage Examples**:
  - *Formal*: "I'm following up on the API credentials request I sent last Tuesday — could you check if the team has approved it?"
  - *Casual*: "Just following up — did you get a chance to review my PR?"
- **Common Mistake**: Following up too aggressively or too passively. One follow-up after 2-3 days is professional. Five follow-ups in two days is annoying. No follow-up at all means things get forgotten.

### "Wrap up"
- **Pronunciation**: "rap up" · راب أب
- **Arabic**: إنهاء / اختتام
- **Meaning**: To finish or conclude something — a meeting, a sprint, a task.
- **Usage Examples**:
  - *Formal*: "Let's wrap up this sprint review — I'll send the summary notes to all stakeholders."
  - *Casual*: "I'm wrapping up the migration script — should be done by EOD."
- **Common Mistake**: Using "wrap up" for tasks that are nowhere near completion. "Wrapping up" implies 90%+ done, just tying loose ends. If you're at 50%, say "still working on it."

### "Roll out"
- **Pronunciation**: "rohl out" · رول أوت
- **Arabic**: نشر / إطلاق
- **Meaning**: To release, deploy, or introduce something new — a feature, a product, a policy.
- **Usage Examples**:
  - *Formal*: "We plan to roll out the new billing system to 10% of users first, then gradually expand to the full user base."
  - *Casual*: "When are we rolling out the dark mode feature?"
- **Common Mistake**: Using "roll out" and "deploy" interchangeably. A deployment is the technical act of pushing code. A rollout is the broader process of making a feature available to users, which might include phased releases, feature flags, and communication.

### "Spin up"
- **Pronunciation**: "spin up" · سبِن أب
- **Arabic**: تشغيل / إعداد
- **Meaning**: To quickly start or create something — a server, a container, a prototype, a new environment.
- **Usage Examples**:
  - *Formal*: "We can spin up a staging environment in minutes using our Docker Compose configuration."
  - *Casual*: "Let me spin up a quick prototype to show the client."
- **Common Mistake**: Using "spin up" for complex, time-consuming setups. If it takes two days of configuration, you're not "spinning it up" — you're "setting it up" or "provisioning it."

---

### "Point out"
- **Pronunciation**: "poynt out" · بوينت أوت
- **Arabic**: أشار إلى / نبّه على
- **Meaning**: To bring attention to something — an issue, a mistake, an improvement opportunity.
- **Usage Examples**:
  - *Formal*: "I'd like to point out that this query runs without an index, which could cause performance issues at scale."
  - *Casual*: "Good catch pointing that out in the code review — I missed the edge case."
- **Common Mistake**: Being too blunt. "I want to point out that your code is wrong" is harsh. "I noticed something that might cause issues — would you take a look?" is the same message delivered professionally.
