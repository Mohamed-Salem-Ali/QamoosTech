# Security & Compliance

### Field-Level Encryption
- **Definition**: Encrypting specific data fields within a database table rather than encrypting the entire database or disk.
- **Context/Stack**: Backend / Data Security
- **Usage Examples**:
  - *Technical*: "We protect patient PII with field-level encryption and hashed lookups."
- **Related Terms**: Encryption at rest, PII (Personally Identifiable Information)

### GDPR-Compliant
- **Definition**: Designing systems to adhere to the General Data Protection Regulation, typically involving the right to be forgotten (data deletion).
- **Context/Stack**: Backend / Legal Compliance
- **Usage Examples**:
  - *Technical*: "I implemented a two-step GDPR-compliant deletion flow to ensure all user data is fully wiped upon request."
- **Related Terms**: Right to be forgotten, PII
