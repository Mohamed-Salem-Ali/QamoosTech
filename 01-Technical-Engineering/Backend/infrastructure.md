# Infrastructure & DevOps

### CI/CD (Continuous Integration / Continuous Deployment)
- **Definition**: A method to frequently deliver apps to customers by introducing automation into the stages of app development.
- **Context/Stack**: DevOps / Release Management
- **Usage Examples**:
  - *Technical*: "Our Bitbucket Pipelines handle the CI/CD, running tests and deploying to AWS Fargate."
  - *Conversational*: "I'll merge this PR, and the CI/CD pipeline will automatically push it to staging."
- **Related Terms**: Automation, Deployment, Pipeline

### Reverse Proxy
- **Definition**: A type of proxy server that retrieves resources on behalf of a client from one or more servers.
- **Context/Stack**: DevOps / Server Management
- **Usage Examples**:
  - *Technical*: "Nginx acts as a reverse proxy, forwarding requests to our Gunicorn application servers."
  - *Conversational*: "We need to configure the reverse proxy to handle SSL termination."
- **Related Terms**: Nginx, Load Balancer, Forwarding
