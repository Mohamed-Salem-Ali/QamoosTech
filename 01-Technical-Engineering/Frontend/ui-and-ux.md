# UI & UX Terminology

### RTL (Right-to-Left)
- **Definition**: A design and development approach ensuring that text and UI components flow correctly for languages like Arabic or Hebrew.
- **Context/Stack**: Frontend / Localization
- **Usage Examples**:
  - *Technical*: "The storefront is built to be Arabic-first and fully RTL compliant."
- **Related Terms**: LTR, Localization (L10n), Internationalization (i18n)
