# Frontend Tools & Patterns

### Next.js
- **Definition**: A React framework that enables server-side rendering and generating static websites.
- **Context/Stack**: Frontend / React
- **Usage Examples**:
  - *Technical*: "We migrated the frontend to Next.js to improve SEO and first-contentful-paint times."
- **Related Terms**: SSR (Server-Side Rendering), React

### Spaced Repetition (SM-2 Algorithm)
- **Definition**: A learning technique that incorporates increasing intervals of time between subsequent review of previously learned material.
- **Context/Stack**: Frontend / EdTech Algorithms
- **Usage Examples**:
  - *Technical*: "I implemented a real SM-2 spaced-repetition algorithm that tracks ease factor and intervals."
- **Related Terms**: Flashcards, Cognitive Science
