## Definition

JSON (JavaScript Object Notation) is a lightweight text format for structured data, built from objects (`{}`), arrays (`[]`), strings, numbers, booleans and `null`. Most web APIs use it.

## Where you hear it

In API docs, request and response bodies, config files, and logs.

## Examples

- The API returns JSON with the member's name and balance.
- Parse the JSON body, then validate the fields.

## Common mistake

Thinking JSON is a JavaScript object. It is only text; it needs strict double quotes, and no comments or trailing commas.

## Don't confuse with

A Python dict, which is a live object in memory. JSON is the text you convert it to when sending it.

## Say it at work

- Send it as JSON with the right content type.
- The JSON is invalid; there's a trailing comma.
