## Definition

The basic pattern of the web: a client sends a request, and the server sends back a response with data and a status.

## Where you hear it

API documentation, debugging in the browser Network tab, and logs.

## Examples

- The response took 3 seconds, so the page felt slow.
- Check the request body in the Network tab.

## Common mistake

Mixing up the two when reporting bugs. Say clearly whether the problem is in what you sent or in what came back.

## Say it at work

- Let us check the payload of this request and see what response the server returns.
- Please attach the request headers and the response logs to the Jira ticket.
