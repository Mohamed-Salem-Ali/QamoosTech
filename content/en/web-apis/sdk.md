## Definition

A collection of software tools, libraries, and documentation provided by a platform or service to help developers build applications for it.

## Where you hear it

When integrating third-party services, setting up mobile apps, or working with cloud platforms.

## Examples

- We used the Stripe SDK to process credit card payments in our app.
- The new mobile SDK makes it easy to track user analytics.

## Common mistake

Thinking an SDK is just an API, when actually the SDK is a package containing helper code that makes calling the API easier.
