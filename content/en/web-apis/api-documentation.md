## Definition

API documentation is a technical guide that explains how to use and integrate with an API. It typically includes details about available endpoints, request parameters, and example responses.

## Where you hear it

During API development, onboarding new developers, or when integrating a third-party service.

## Examples

- Please check the API documentation to see which fields are required for this request.
- Our team needs to update the API documentation before we release the new version.

## Common mistake

Assuming that the code is self-documenting and skipping the creation of a formal guide, which makes it difficult for other developers to understand how to interact with the system.
