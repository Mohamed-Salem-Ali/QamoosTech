## Definition

A web framework is a toolkit that handles the common parts of building a web application, such as routing, requests and responses, templates, security and database access.

## Where you hear it

When choosing a stack (Django, Flask, FastAPI, Express, Next.js), in job posts, and in architecture talks.

## Examples

- Django is a full-featured framework; Flask is a microframework.
- The framework calls your code, not the other way around.
- The web framework gives us the login, sessions and admin pages out of the box.

## Common mistake

Mixing it up with a library. You call a library; a framework calls you and sets the structure of your app.

## Don't confuse with

A library, which does one job when you call it, like `requests` for HTTP calls.

## Say it at work

- Which framework fits this project?
- The framework gives us auth and an admin panel out of the box.
