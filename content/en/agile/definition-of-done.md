## Definition

The Definition of Done is a shared checklist of criteria that a task or user story must satisfy before it is considered complete. It ensures that all work meets the team's quality standards before being marked as finished.

## Where you hear it

During sprint planning, daily stand-ups, or when reviewing the team's working agreement.

## Examples

- We need to update our Definition of Done to include automated test coverage.
- This ticket does not meet our Definition of Done because the documentation is missing.

## Common mistake

Thinking that the Definition of Done is the same as the acceptance criteria for a specific feature; while acceptance criteria are unique to each task, the DoD applies to every single item the team works on.
