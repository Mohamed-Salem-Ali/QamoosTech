## Definition

A time-boxed task dedicated to research, design, or prototyping to answer a technical question before estimating real work.

## Where you hear it

In sprint planning meetings, backlog refinement sessions, or when facing an unknown technical challenge.

## Examples

- We need a two-day spike to figure out which third-party payment gateway fits our security requirements.
- Let us create a spike ticket to test if this database migration tool handles our table size.

## Common mistake

Treating a spike as an open-ended research project without a clear time limit or a defined output goal.

## Don't confuse with

Spike is often confused with a regular user story; however, a spike is meant to gain knowledge and reduce uncertainty, whereas a user story delivers functional value to the end user.

## Say it at work

- I'm not sure how this library handles concurrency, so let's run a quick spike before we commit to using it.
- I have created a spike ticket to investigate the integration issues; please review the scope to ensure it remains time-boxed.
