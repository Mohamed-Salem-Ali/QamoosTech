## Definition

A dependency is a situation where one task, feature, or team relies on another task being completed first before it can proceed.

## Where you hear it

In sprint planning meetings, project status updates, and when discussing project timelines and blockers.

## Examples

- Our user authentication feature has a dependency on the backend API being deployed first.
- We cannot start testing until we resolve this database dependency.

## Common mistake

Treating all dependencies as equal, rather than identifying which ones are on the critical path and actually block progress.
