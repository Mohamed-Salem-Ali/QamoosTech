## Definition

Work on an existing system, with its own code and data, and with customers who need it to keep working while you change it.

## Where you hear it

In estimates and planning, when a task touches code the team already runs in production.

## Examples

- Adding a field to a brownfield database needs a careful migration.
- Brownfield tasks usually take longer than the first estimate.
- Adding a new payment option to the existing checkout is brownfield work.

## Common mistake

Estimating brownfield work as if it were greenfield, and forgetting the time needed to understand the existing code.

## Don't confuse with

Greenfield starts from nothing. Brownfield work happens inside a system that already exists.
