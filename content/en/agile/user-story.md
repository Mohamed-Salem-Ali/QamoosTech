## Definition

A short description of a feature from the user's view: "As a [user], I want [goal], so that [benefit]".

## Where you hear it

Planning and requirement discussions.

## Examples

- As a customer, I want to reset my password, so that I can log in again.
- This user story is too big. Let's split it.

## Common mistake

Writing technical tasks instead of user needs. A story should explain the value for the user.
