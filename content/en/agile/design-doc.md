## Definition

A document that describes how a feature or system will be built, including the design, the main trade-offs, and the plan for the rollout.

## Where you hear it

In engineering planning meetings, design reviews, and onboarding documents for new engineers.

## Examples

- Read the design doc before you touch the billing module.
- The design doc lists three options and explains why we picked the queue.

## Common mistake

Writing the design doc after the code is finished, so it only describes what already exists.

## Don't confuse with

A spec describes the required behaviour. A design doc describes the chosen design for building it.
