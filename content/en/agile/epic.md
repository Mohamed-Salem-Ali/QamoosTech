## Definition

A large body of work in agile development that is too big for a single sprint and must be broken down into smaller user stories.

## Where you hear it

During backlog refinement, release planning, and product roadmap discussions.

## Examples

- We created a new epic to track the entire user authentication redesign.
- This feature is too large for the current sprint, so we should convert it into an epic.

## Common mistake

Treating an epic as a single task instead of a container for many smaller user stories and tasks.
