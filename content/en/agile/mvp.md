## Definition

The simplest version of a product that real users can use, built to test an idea quickly before investing more.

## Where you hear it

Startups and client projects.

## Examples

- For the MVP we will only build login and the main list.
- Let's launch the MVP and learn from real users.

## Common mistake

Treating "minimum" as "bad quality". It means few features, but they should still work well.
