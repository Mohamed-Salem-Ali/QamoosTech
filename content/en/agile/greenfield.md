## Definition

A project that starts from nothing, with no existing code or constraints to work around.

## Where you hear it

In planning discussions, when choosing a stack, or when describing a new product.

## Examples

- This is a greenfield project, so we can pick the newest framework.
- Greenfield work is faster at the start, but it has no history to learn from.
- The new analytics product is greenfield, so the team can design the data model from scratch.

## Common mistake

Assuming a greenfield project will stay simple. It grows, and the early shortcuts become the next legacy code.

## Don't confuse with

Brownfield work changes an existing system. Greenfield starts a new one.
