## Definition

Waterfall is a project method where work flows in fixed phases, one after the other (requirements, design, build, test, release), and each phase ends before the next one starts.

## Where you hear it

In agile vs traditional comparisons, contracts and fixed-scope projects, and interviews about project methodologies.

## Examples

- The government contract was run as waterfall with signed-off phases.
- In waterfall, a change late in testing is expensive.
- The compliance project used waterfall, so the design was frozen before any coding started.

## Common mistake

Calling it always wrong. It can suit projects with fixed, well-understood requirements and strict approvals.

## Don't confuse with

Agile, which works in short iterations and expects requirements to change.

## Say it at work

- Is this project waterfall or agile?
- Sign off on the design phase before we build.
