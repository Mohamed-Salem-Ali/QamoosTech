## Definition

A proven, reusable solution to a common design problem, with a name everyone knows, such as Singleton, Factory, or Observer.

## Where you hear it

Interviews, code reviews, and architecture talks.

## Examples

- This is the Observer pattern: subscribers get notified on every change.
- Do not force a pattern where a simple function is enough.

## Common mistake

Using patterns just to look advanced. Use one only when it solves a real problem.
