## Definition

Vertical scaling means handling more load by giving one machine more power, such as more CPU, memory or faster disks.

## Where you hear it

In database sizing, cloud instance choices, and "quick fix" discussions during incidents.

## Examples

- We scaled the database up to a larger instance.
- Vertical scaling is easy but there is a limit and it is one machine.

## Common mistake

Treating it as the long-term plan. It has a ceiling, costs more per unit and keeps a single point of failure.

## Don't confuse with

Horizontal scaling, which adds more machines.

## Say it at work

- Let's scale up the instance for now.
- We're near the largest size available.
