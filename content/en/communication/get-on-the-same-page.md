## Definition

To reach a shared understanding or agreement among team members regarding a project, task, or requirement. It ensures everyone is working toward the same goal with the same information.

## Where you hear it

During team meetings, project syncs, or when resolving misunderstandings about a feature's requirements.

## Examples

- Let's have a quick call to get on the same page about the project requirements.
- We need to get on the same page before we start implementing this feature.

## Common mistake

Thinking that "getting on the same page" means everyone must agree with every detail, rather than simply ensuring everyone has the same interpretation of the facts and goals.

## Say it at work

- Let us take five minutes to get on the same page regarding the API response format before we continue.
- I left a comment on the ticket to help us get on the same page about the expected edge cases.
