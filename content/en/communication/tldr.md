## Definition

A one-line summary placed at the top of a long message, so the reader knows the point before reading the details.

## Where you hear it

At the start of a long pull request description, a design document, or an email.

## Examples

- TL;DR: the fix is safe, but it needs a database migration.
- Add a TL;DR so reviewers know what to focus on.
- TL;DR: the bug is fixed, and the release can go out today.

## Common mistake

Writing a TL;DR that is longer than the message it summarizes, or that leaves out the decision.

## Don't confuse with

A TL;DR summarizes text that is already written. An introduction at the start of a report presents the report before its details.
