## Definition

A small, minor comment in a review, about style or wording, that does not block the change. Reviewers often mark it as a nit so the author knows it is optional.

## Where you hear it

In pull request comments and code review threads.

## Examples

- Nit: this variable name could be clearer.
- Just a nitpick, but the comment has a typo.
- Nitpick: please add a space after the comma in this list.

## Common mistake

Using nitpicks to block a merge. If the comment is not required, say so and do not hold up the review.

## Don't confuse with

A nitpick is minor and optional. A blocking comment must be fixed before the change is merged.

## Say it at work

- Nit: please add a space after the comma.
