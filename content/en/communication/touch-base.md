## Definition

To have a short, informal conversation to share updates or check that everything is okay.

## Where you hear it

Meetings and manager or client check-ins.

## Examples

- Let's touch base on Thursday about the release.
- I wanted to touch base before the deadline.

## Common mistake

Using it when you have a specific request. If you need something, say it directly.

## Don't confuse with

Touch base is often confused with 'sync up', but while touch base implies a quick check-in or status update, sync up usually refers to aligning on specific technical details or project requirements.

## Say it at work

- Do you have a minute to touch base about the new API documentation?
- I would like to touch base regarding the progress of the current sprint before our weekly meeting.
