## Definition

To identify and notify team members about a potential problem, risk, or concern that requires attention. It is a proactive way to highlight something that might derail a project or task.

## Where you hear it

In stand-up meetings, project management tools, or team communication channels.

## Examples

- Please flag an issue if you notice any discrepancies in the documentation.
- I need to flag an issue regarding the current API response time.

## Common mistake

Confusing "flagging" with "complaining"; flagging is intended to be a constructive step to resolve a problem early, not just to criticize.

## Don't confuse with

Flagging an issue is often confused with reporting a bug; flagging is a proactive alert about a potential risk or blocker, whereas reporting a bug is a formal record of a confirmed defect.

## Say it at work

- I'm going to flag an issue with the database migration plan since we might hit some performance bottlenecks.
- I would like to flag an issue regarding the upcoming deadline, as the current resource allocation appears insufficient to meet our requirements.
