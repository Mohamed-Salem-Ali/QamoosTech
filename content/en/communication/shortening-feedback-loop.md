## Definition

Reducing the time between doing work and learning whether it is right, from users, clients, or automatic tests.

## Where you hear it

Agile talks and client communication.

## Examples

- Weekly demos shortened the feedback loop with the client.
- Fast tests shorten the feedback loop for developers.
- Running the test suite on every save shortened the feedback loop for the developers.

## Common mistake

Confusing fast feedback with skipping checks. Show early prototypes, but do not ship untested code.

## Say it at work

- Can we set up automated deployments to staging to help with shortening the feedback loop?
- This change aims at shortening the feedback loop for QA engineers before merging the pull request.
