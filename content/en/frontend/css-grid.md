## Definition

CSS Grid is a two-dimensional layout system that allows you to align items in both rows and columns simultaneously. It provides a powerful way to create complex web page layouts with minimal code.

## Where you hear it

During frontend development meetings, code reviews, or when discussing responsive design implementations.

## Examples

- We should use CSS Grid to structure the main dashboard layout.
- The new photo gallery uses CSS Grid to maintain a perfect alignment across different screen sizes.

## Common mistake

Thinking that CSS Grid replaces Flexbox; in reality, they are meant to be used together, where Grid handles the overall page structure and Flexbox handles the alignment of items within smaller components.
