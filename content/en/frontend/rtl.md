## Definition

A layout direction for languages like Arabic and Hebrew, where text and the whole interface flow from right to left.

## Where you hear it

Localization work and Arabic-first products.

## Examples

- The app supports RTL, so the menu is on the right side.
- Use logical CSS properties like `margin-inline-start` instead of `margin-left`.

## Common mistake

Only changing `text-align: right`. Real RTL support mirrors the whole layout, not just the text.
