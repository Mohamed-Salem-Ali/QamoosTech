## Definition

A file format that lets you write React components inside Markdown text.

## Where you hear it

Documentation sites, blogs, and learning platforms.

## Examples

- Each lesson is an MDX file with a few custom components.
- Use plain Markdown unless you really need a component.

## Common mistake

Putting too much logic into MDX files. Keep content simple and logic in components.

## Don't confuse with

MDX is often confused with standard Markdown, but while Markdown only supports static text formatting, MDX allows for the integration of interactive React components.

## Say it at work

- Let's switch this documentation page to MDX so we can embed the live preview component directly.
- I have updated the blog post to an MDX file to include the interactive chart component as requested.
