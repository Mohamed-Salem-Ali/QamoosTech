## Definition

A popular framework built on React that adds routing, server rendering, and many performance features.

## Where you hear it

Job posts, frontend projects, and full-stack tutorials.

## Examples

- We built the marketing site with Next.js.
- Next.js handles routing, so we do not need extra libraries.

## Common mistake

Marking every component as a client component. Keep components on the server unless they need interaction.

## Don't confuse with

Next.js is often confused with React, but React is just a UI library while Next.js is a full-featured framework built on top of it.

## Say it at work

- Let us use Next.js for this project to get built-in server-side rendering and better SEO out of the box.
- Please ensure that data fetching is optimized by leveraging Next.js static generation where appropriate.
