## Definition

A popular framework built on React that adds routing, server rendering, and many performance features.

## Where you hear it

Job posts, frontend projects, and full-stack tutorials.

## Examples

- We built the marketing site with Next.js.
- Next.js handles routing, so we do not need extra libraries.

## Common mistake

Marking every component as a client component. Keep components on the server unless they need interaction.
