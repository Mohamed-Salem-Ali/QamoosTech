## Definition

A PWA is a website built with extra web features (a manifest, a service worker, HTTPS) so it can be installed on a phone or desktop, work offline and feel like an app.

## Where you hear it

In frontend project planning, "do we need a mobile app?" discussions, Lighthouse audits and offline-first features.

## Examples

- Our dashboard is a PWA, so field staff install it from the browser.
- The service worker caches the pages for offline use.
- Users can add the PWA to their home screen and open it without the browser bar.

## Common mistake

Expecting every native feature. Some device APIs, especially on iOS, are limited for PWAs.

## Don't confuse with

A native app, which is built per platform and distributed through app stores.
