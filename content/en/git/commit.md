## Definition

A saved snapshot of your changes in Git, with a message that explains what changed and why.

## Where you hear it

Daily Git work and code reviews.

## Examples

- Commit your changes with a clear message.
- This commit fixes the login bug.

## Common mistake

Writing messages like "fix" or "update". Say what changed and why.
