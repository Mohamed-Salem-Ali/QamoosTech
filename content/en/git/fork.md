## Definition

Your own copy of someone else's repository on GitHub, where you can make changes and then suggest them back with a pull request.

## Where you hear it

Open source contributions.

## Examples

- Fork the repo, fix the typo, and open a pull request.
- Our company keeps a private fork of the library.

## Common mistake

Letting a fork fall behind the original. Sync it regularly.
