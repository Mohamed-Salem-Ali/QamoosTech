## Definition

A separate line of work in Git, so you can build a feature without affecting the main code.

## Where you hear it

Team workflows ("create a branch for the ticket").

## Examples

- Create a new branch for the payment feature.
- Do not push directly to the `main` branch.

## Common mistake

Keeping a branch alive for weeks. The longer it lives, the harder it is to merge.
