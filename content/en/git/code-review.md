## Definition

When teammates read your changes before they are merged, to find bugs, improve quality, and share knowledge.

## Where you hear it

Every professional team.

## Examples

- Can you review my pull request today?
- The code review caught a security bug.

## Common mistake

Giving blunt comments like "this is wrong". Explain why and suggest a better way.
