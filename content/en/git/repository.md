## Definition

A folder that Git tracks, containing your project files and the full history of their changes. Often shortened to "repo".

## Where you hear it

Every team: "clone the repo", "open the repo".

## Examples

- Clone the repository and run `npm install`.
- The repo is private, so ask for access.

## Common mistake

Committing large files and secrets. Once in history, they are hard to remove completely.

## Don't confuse with

Repository refers to the entire tracked project folder with its history, whereas a branch is just a single line of development within that repository.

## Say it at work

- Can you share the link to the new repository so I can clone it?
- Please make sure your code changes are pushed to the main repository before creating the pull request.
