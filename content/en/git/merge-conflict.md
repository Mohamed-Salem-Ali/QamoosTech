## Definition

When Git cannot combine two changes automatically because both edited the same lines, so a person must choose.

## Where you hear it

Any team project.

## Examples

- I have a merge conflict in `package.json`.
- Resolve the conflict, then commit the result.
- The merge conflict was in the checkout template, so I kept both changes.

## Common mistake

Choosing "accept all mine" without reading. You may delete a teammate's work.

## Don't confuse with

A merge conflict happens when Git cannot automatically combine overlapping edits, whereas a build error occurs when code compiles incorrectly regardless of how it was merged.

## Say it at work

- Hey, could you hop on a quick call with me to help resolve this merge conflict?
- I have updated the branch and resolved the merge conflict in the configuration file.
