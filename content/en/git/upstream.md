## Definition

Upstream refers to the original repository that you forked from, or the default remote branch that your local branch tracks for pulling and pushing changes.

## Where you hear it

When pulling the latest changes from the main project or configuring git remotes.

## Examples

- Run `git remote add upstream` to link your fork to the original repository.
- Always fetch from the upstream repository before starting a new feature.

## Common mistake

Confusing upstream with origin, where origin is your own remote repository and upstream is the original main project.
