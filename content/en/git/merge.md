## Definition

Combining the changes from one branch into another, usually a feature branch into `main`.

## Where you hear it

Pull requests and release time.

## Examples

- The pull request was approved and merged.
- Merge `main` into your branch to get the latest changes.

## Common mistake

Merging without running the tests. Always let the checks finish first.
