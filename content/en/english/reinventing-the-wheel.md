## Definition

Building something from scratch when a good solution already exists.

## Where you hear it

Code reviews and technical decisions.

## Examples

- Don't reinvent the wheel. Use the existing library.
- Writing our own date library is reinventing the wheel.

## Common mistake

Using it to reject every custom solution. Sometimes security or licensing needs your own code.
