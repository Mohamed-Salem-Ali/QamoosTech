## Definition

To start or create something quickly, like a server, a container, or a test environment.

## Where you hear it

DevOps and daily engineering talk.

## Examples

- I can spin up a test server in five minutes.
- Let me spin up a quick prototype for the client.

## Common mistake

Using it for work that takes days. Then say "set up" instead.
