## Definition

The extra cost of future work that comes from quick shortcuts today. Like financial debt, it grows if you ignore it.

## Where you hear it

Planning, refactoring, and engineering management.

## Examples

- We took on tech debt to hit the deadline and will fix it next sprint.
- This module has a lot of tech debt.

## Common mistake

Treating all tech debt as bad. A deliberate shortcut with a repayment plan can be a good decision.

## Don't confuse with

Tech debt is often confused with legacy code; while tech debt refers to shortcuts taken to speed up delivery, legacy code refers to older, often unmaintained code that may or may not have been written poorly.

## Say it at work

- We really need to address some of this tech debt before we start building the new feature.
- I have documented the tech debt in this PR and added a follow-up ticket to resolve it in the next cycle.
