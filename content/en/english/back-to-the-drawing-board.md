## Definition

To start planning again from the beginning because the first plan failed.

## Where you hear it

Design and project discussions.

## Examples

- The client rejected the design, so it's back to the drawing board.
- The prototype failed. Back to the drawing board.

## Common mistake

Using it for small problems. A failed test is not "back to the drawing board".
