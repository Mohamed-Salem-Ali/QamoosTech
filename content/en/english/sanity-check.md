## Definition

A quick, informal test to ensure that a piece of code, a configuration, or a logic flow is fundamentally reasonable before doing deeper work.

## Where you hear it

In code reviews, testing discussions, and daily standups.

## Examples

- Let us do a quick sanity check on the numbers before pushing this update to production.
- I ran a sanity check on the API response to make sure the data format looks correct.
- A quick sanity check showed the totals were in cents instead of dollars.

## Common mistake

Treating a sanity check as a complete, rigorous test suite rather than a fast, surface-level verification.

## Don't confuse with

A sanity check is a quick, basic check to ensure a solution is generally reasonable, whereas unit testing is a formal, automated suite that thoroughly verifies specific functions.

## Say it at work

- Can we do a quick sanity check on the login form before we call this ticket done?
- I performed a sanity check on the deployment outputs to ensure the basic routes are responding correctly.
