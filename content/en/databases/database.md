## Definition

An organized system for storing data so programs can save, search, and update it reliably.

## Where you hear it

Every backend project and job description.

## Examples

- We store users and orders in a PostgreSQL database.
- The database is down, so the app cannot log anyone in.

## Common mistake

Treating the database as a place for temporary files. It is for structured data you need to query.
