## Definition

A request to the database to read or change data, usually written in SQL.

## Where you hear it

Performance work: "this query is slow".

## Examples

- Run this query to find all unpaid invoices.
- The query takes 8 seconds because there is no index.

## Common mistake

Building queries by joining strings with user input. That opens the door to SQL injection; use parameters.
