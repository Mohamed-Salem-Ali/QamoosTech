## Definition

A *table* holds one kind of data. Each *row* is one record (one user). Each *column* is one field (the email).

## Where you hear it

SQL lessons and database design discussions.

## Examples

- The `users` table has a column called `email`.
- This query updates only one row.

## Common mistake

Saying "row" when you mean the whole table. A row is one record only.

## Don't confuse with

Table vs. View: A table is a physical storage structure that holds actual data, whereas a view is a virtual table based on the result-set of an SQL statement.

## Say it at work

- Could you check if we need to add a new column to the orders table to track the shipping status?
- I noticed that the migration script failed because it tried to insert a duplicate value into a unique column for this row.
