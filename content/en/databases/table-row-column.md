## Definition

A *table* holds one kind of data. Each *row* is one record (one user). Each *column* is one field (the email).

## Where you hear it

SQL lessons and database design discussions.

## Examples

- The `users` table has a column called `email`.
- This query updates only one row.

## Common mistake

Saying "row" when you mean the whole table. A row is one record only.
