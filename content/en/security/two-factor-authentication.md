## Definition

Logging in with two proofs: something you know (password) and something you have (a phone code).

## Where you hear it

Account security settings.

## Examples

- Enable two-factor authentication on your GitHub account.
- The code expires after 30 seconds.

## Common mistake

Sending the code by SMS only. Authenticator apps are safer because SMS can be intercepted.
