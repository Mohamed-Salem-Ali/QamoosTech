## Definition

Any data that can identify a person: name, phone number, email, national ID, address.

## Where you hear it

Privacy policies, security reviews, and data handling rules.

## Examples

- Do not log any PII.
- Mask the PII before sending data to analytics.

## Common mistake

Thinking only names are PII. Emails, phone numbers, and IP addresses can be PII too.

## Don't confuse with

PII is often confused with Sensitive Personal Information (SPI); while PII identifies a person, SPI refers to a narrower subset of data that requires higher protection, such as medical records or biometric data.

## Say it at work

- We need to make sure we aren't accidentally exposing any PII in the debug logs.
- Please ensure that all PII fields are properly encrypted before they are stored in the database.
