## Definition

Logging in with two proofs: something you know (password) and something you have (a phone code).

## Where you hear it

Account security settings.

## Examples

- Enable two-factor authentication on your GitHub account.
- The code expires after 30 seconds.
- After we turned on two-factor authentication, login attempts from bots dropped sharply.

## Common mistake

Sending the code by SMS only. Authenticator apps are safer because SMS can be intercepted.

## Don't confuse with

Two-factor authentication requires two different categories of verification factors, while two-step verification can simply use two successive prompts of the same category, such as a password followed by an SMS code.

## Say it at work

- Can we enforce two-factor authentication for all developers on the team?
- Please ensure that two-factor authentication is configured correctly before accessing the production environment.
