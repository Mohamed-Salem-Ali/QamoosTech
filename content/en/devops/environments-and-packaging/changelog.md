## Definition

A file or log that lists every notable change in each version of a project, in order, so developers can see what changed and when.

## Where you hear it

In the root of open-source repositories, and in package releases on registries such as PyPI or npm.

## Examples

- Check the changelog before you upgrade to version 3.
- Our changelog groups changes into added, changed, and fixed.
- The changelog says version 2.1 removed the old login endpoint.

## Common mistake

Letting the changelog fall behind the releases, so it no longer tells the truth.

## Don't confuse with

A changelog is a complete technical history. Release notes are a short summary for the people who use the product.
