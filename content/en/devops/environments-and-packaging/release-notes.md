## Definition

A short document that tells users what changed in a release: new features, fixes, and anything they must do differently.

## Where you hear it

On a product page, in an app store update, and in an email announcing a new version.

## Examples

- The release notes mention the new export format and two bug fixes.
- Write the release notes for users, not for developers.
- The release notes tell users that the old export format will stop working in March.

## Common mistake

Copying a list of commit messages as release notes. Users need the effect of each change, not the internal details.

## Don't confuse with

Release notes are for users and describe the effect of a release. A changelog is a complete, technical list of changes.
