## Definition

PyPI, the Python Package Index, is the public website where Python packages are published and from which pip downloads them.

## Where you hear it

When installing a library, publishing your own package, or checking a package's versions and maintainers.

## Examples

- The package is on PyPI, so `pip install` finds it.
- Check the PyPI page for the latest release.
- The new version of the package appeared on PyPI an hour after the release.

## Common mistake

Installing a package just because the name looks right. Typo-squatted names exist; check the project page and its maintainers.

## Don't confuse with

GitHub, which hosts source code. PyPI hosts built packages ready to install.

## Say it at work

- We'll publish the first release to PyPI.
- Try TestPyPI first before the real upload.
