## Definition

Watching the health of a system with numbers and alerts, such as errors, speed, and CPU use, to catch problems early.

## Where you hear it

Production support and on-call work.

## Examples

- Monitoring alerted us before any customer noticed the problem.
- Set up an alert when the error rate goes above 2%.
- The dashboard shows the error rate, and an alert fires above 2 percent.

## Common mistake

Creating so many alerts that everyone ignores them. Alert only on things that need action.

## Don't confuse with

Monitoring is often confused with observability; while monitoring tells you that a system is broken, observability provides the internal data needed to understand why it is broken.

## Say it at work

- Let's check our monitoring dashboard to see if the latency spikes are still happening.
- I have updated the monitoring configuration to include more granular metrics for the database service.
