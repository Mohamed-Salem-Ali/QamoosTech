## Definition

A managed service is an IT offering where a third-party provider manages, maintains, and supports a specific infrastructure or software component for a client. This allows the client to focus on their application code rather than server patching or hardware maintenance.

## Where you hear it

In cloud architecture discussions, vendor selection meetings, and infrastructure planning.

## Examples

- We decided to use a managed service for our database to avoid manual backups and patching.
- Using a managed service reduces the operational burden on our small engineering team.

## Common mistake

Thinking that using a managed service removes the need for any configuration or monitoring; you still need to manage your application settings and resource scaling policies.
