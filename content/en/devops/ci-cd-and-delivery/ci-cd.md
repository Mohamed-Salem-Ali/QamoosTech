## Definition

Automation that tests every code change (CI) and then delivers it to a server (CD), so releases are fast and repeatable.

## Where you hear it

Job posts, DevOps talks, and pull request checks.

## Examples

- Our CI/CD pipeline runs the tests and deploys on every merge to `main`.
- The CI failed, so the code cannot be merged.
- Every push runs the CI checks, and a merge into main is delivered through CD.

## Common mistake

Mixing up Continuous Delivery and Continuous Deployment. Delivery means "ready to deploy"; deployment means "deployed automatically".

## Say it at work

- Can you check why the CI/CD pipeline is failing on the master branch?
- We need to update our CI/CD workflow to run security scans before deploying to production.
