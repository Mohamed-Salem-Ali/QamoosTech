## Definition

A period before a release when no new changes are merged, except fixes approved for that release. It gives the team time to test what will ship.

## Where you hear it

Before a big launch, in release calendars, and in messages that say "we are in code freeze".

## Examples

- We are in code freeze from Wednesday until the release.
- Only security fixes are allowed during the code freeze.
- The code freeze starts Thursday, and only approved fixes can be merged after that.

## Common mistake

Freezing the code without a clear end date or a list of allowed changes. The team then stops working for no clear reason.

## Don't confuse with

A code freeze blocks new changes before a release. A feature freeze blocks new features but still allows fixes.
