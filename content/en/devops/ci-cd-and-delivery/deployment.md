## Definition

Putting a new version of the software on a server so real users can use it. A deployment can replace the old version all at once or roll it out gradually, and it usually runs through a pipeline that builds, tests, and then ships the code.

## Where you hear it

Daily team talk: "when is the deployment?"

## Examples

- The deployment is scheduled for Thursday morning.
- The deployment failed because an environment variable was missing.
- The deployment rolled out to ten percent of users before the full release.

## Common mistake

Deploying on Friday evening without a rollback plan. Deploy when people are available to fix problems.

## Don't confuse with

Deployment makes code available on a server, while a release makes that software available to the end users.

## Say it at work

- Let us wait for the morning standup before we trigger the deployment.
- Please hold off on the deployment until the security scan finishes successfully.
