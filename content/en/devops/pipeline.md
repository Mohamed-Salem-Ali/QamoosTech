## Definition

A pipeline is a series of automated steps that takes software code from a git commit all the way to production.

## Where you hear it

In CI/CD setups, build automation meetings, and DevOps discussions.

## Examples

- The build failed because the test stage in the pipeline broke.
- We added a new security scan to our deployment pipeline.

## Common mistake

Thinking a pipeline is just a single script, rather than a coordinated sequence of distinct stages like build, test, and deploy.

## Don't confuse with

A pipeline is a sequence of automated stages for building and deploying software, whereas CI/CD refers to the broader set of practices and tools that the pipeline automates.

## Say it at work

- Could you check why our staging pipeline is taking so long to finish today?
- I have updated the pipeline configuration to include the new linter check before the build stage.
