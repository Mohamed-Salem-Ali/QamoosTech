## Definition

An upfront payment made by a client before any development work begins, used to secure the project and cover initial costs.

## Where you hear it

In freelance contract negotiations, project kickoffs, and payment discussions.

## Examples

- We require a fifty percent deposit before writing any code.
- The client sent the deposit, so we can start the project today.

## Common mistake

Starting development or writing code before receiving the deposit, which risks non-payment if the client disappears.
