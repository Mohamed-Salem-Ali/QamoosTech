## Definition

A legally binding agreement between a freelancer and a client that defines the project scope, payment terms, deadlines, and intellectual property rights.

## Where you hear it

In client onboarding, before starting any development work, or when discussing project terms.

## Examples

- Always sign a freelance contract before writing any code for a new client.
- The freelance contract specifies the hourly rate and the total number of revision rounds.

## Common mistake

Starting a project based only on a chat message or verbal agreement without a signed contract, which leads to unpaid work and scope creep.
