## Definition

A REPL (read-eval-print loop) is an interactive prompt where you type a piece of code, see its result immediately, and repeat.

## Where you hear it

In beginner tutorials, when someone wants to test an idea quickly, and in debugging sessions.

## Examples

- Open the REPL and try the expression before putting it in the file.
- I tested the regex in the REPL first.

## Common mistake

Writing long programs in the REPL. Nothing is saved when you close it, so move working code into a file.

## Don't confuse with

A script, which is a saved file you run from start to finish.

## Say it at work

- Quick check: try it in the REPL.
- I reproduced the bug in a REPL session.
