## Definition

A named place in memory that stores a value your program can read and change.

## Where you hear it

In every programming tutorial, code review, and bug report.

## Examples

- Store the user's age in a variable called `age`.
- The variable is `undefined` because it was never assigned.

## Common mistake

Choosing vague names like `x` or `data`. A good variable name says what it holds, e.g. `invoiceTotal`.
