## Definition

A data type is an attribute that tells a computer system how to interpret the value of data, such as whether it is a number, text, or a boolean. It determines the operations that can be performed on the data and how it is stored in memory.

## Where you hear it

During code reviews, when defining variables, or when reading documentation for a programming language.

## Examples

- The variable stores an integer data type.
- You must ensure the function receives the correct data type.

## Common mistake

Confusing the data type with the actual value itself, or assuming that all languages handle data types in the same way (e.g., static vs. dynamic typing).
