## Definition

An ordered list of values. Each item has a position number called an index, which usually starts at 0.

## Where you hear it

Any time you handle lists: users, products, results.

## Examples

- The API returns an array of users.
- `items[0]` is the first element of the array.

## Common mistake

Forgetting that counting starts at 0, which causes off-by-one errors.
