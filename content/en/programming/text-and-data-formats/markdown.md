## Definition

A plain-text format that uses light symbols for structure. A line starting with # is a heading, a dash starts a list item, and asterisks mark emphasis. Tools turn it into HTML for display.

## Where you hear it

In README files, pull request descriptions, documentation sites, and chat apps.

## Examples

- Write the setup steps in Markdown so they show as a numbered list on GitHub.
- Wrap a command in backticks to show it as code.
- The docs site turns the Markdown files into web pages when it builds.

## Common mistake

Expecting it to look the same everywhere. Renderers support different extras, such as tables, so check it where people will read it.

## Don't confuse with

HTML is what the browser displays, and it is verbose to write by hand. Markdown is the source people write; a tool produces the HTML from it.

## Say it at work

- Can you put the reproduction steps in Markdown in the ticket?
- The table does not render in our old wiki; can we use a list instead?
