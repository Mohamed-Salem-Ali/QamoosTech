## Definition

ISO 8601 is the international standard for writing dates and times as text, for example `2026-10-10` or `2026-10-10T18:30:00Z`.

## Where you hear it

In API documentation, database exports, and any discussion of how dates should travel between systems.

## Examples

- The API returns every date in ISO 8601 format.
- ISO dates sort correctly as plain text.

## Common mistake

Sending dates as `10/11/2026`. It is unclear whether that is the 10th of November or the 11th of October.

## Don't confuse with

A Unix timestamp, which is a number of seconds. ISO 8601 is readable text.

## Say it at work

- Send dates in ISO format and convert them only for display.
- Please include the time zone in the ISO string.
