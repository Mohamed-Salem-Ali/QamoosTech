## Definition

Code that repeats while a condition is true, or once for each item in a collection.

## Where you hear it

Basic tutorials, performance discussions ("this loop is slow"), and code reviews.

## Examples

- Use a `for` loop to go through every order.
- The infinite loop froze the server.

## Common mistake

Forgetting the stop condition, which creates an infinite loop and freezes the program.
