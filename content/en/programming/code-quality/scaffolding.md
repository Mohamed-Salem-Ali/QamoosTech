## Definition

Generating the starting files and folders of a project or component with a command or template, so the team does not write the same setup by hand each time.

## Where you hear it

When starting a new project with a framework command, or creating a new module from a template.

## Examples

- Run the scaffolding command to create the new service.
- The scaffolding creates the folders, the config file, and a first test.
- Scaffolding the new service gave us the folders, the config and a first test in one command.

## Common mistake

Generating a large structure you do not understand. Scaffolding saves time only if the team knows what each file is for.

## Don't confuse with

Scaffolding creates the starting files once. Boilerplate is repeated code that you still have to write or keep in every project.
