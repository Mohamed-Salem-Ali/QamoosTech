## Definition

A third-party library is code written by someone else that you install and use in your project, for example from PyPI or npm.

## Where you hear it

In dependency discussions, security reviews of what a project relies on, and when choosing between writing code and adding a package.

## Examples

- We use a third-party library for date parsing.
- Every third-party library is a dependency we have to keep updated.

## Common mistake

Adding libraries casually. Each one brings update, security and compatibility work; add one only when it earns its place.

## Don't confuse with

The standard library, which ships with the language and does not need installing.

## Say it at work

- Check the library's maintenance before depending on it.
- Pin the third-party libraries so builds are repeatable.
