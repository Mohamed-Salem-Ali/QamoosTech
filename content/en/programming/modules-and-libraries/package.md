## Definition

A package is a folder of related modules you can import together. The word also means a library you install, such as from PyPI or npm.

## Where you hear it

In Python and JavaScript project structure, installation instructions, and dependency discussions.

## Examples

- The `billing` package contains the invoice and payment modules.
- Install the package with pip before running the script.
- The team published the utils package on PyPI, so other projects can install it.

## Common mistake

Using one word for two ideas without noticing. A package can be your own folder of code or something you downloaded; the context tells which.

## Don't confuse with

A module, which is a single file. A package groups modules in a folder.

## Say it at work

- Move these helpers into a package so imports stay tidy.
- Pin the package version in the requirements file.
