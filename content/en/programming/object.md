## Definition

A value that groups related data (properties) and sometimes behavior (methods) under one name.

## Where you hear it

JavaScript and Python basics, JSON payloads, and object-oriented design.

## Examples

- Send the user as a JSON object with `name` and `email`.
- Each `Order` object has a `total` property.

## Common mistake

Mixing up "object" (an instance with real data) and "class" (the blueprint).
