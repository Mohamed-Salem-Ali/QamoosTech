## Definition

Boilerplate refers to sections of code that must be included in many places with little or no alteration to perform a specific task. It is often considered repetitive code that is necessary to satisfy the requirements of a language or framework.

## Where you hear it

- During project setup or configuration.
- When discussing modern frameworks that aim to reduce code verbosity.
- While reviewing code that feels repetitive.

## Examples

- We need to reduce the boilerplate code in our data models.
- This framework generates all the necessary boilerplate for a new API endpoint.

## Common mistake

Thinking that boilerplate is always bad code; while it can be tedious, it is often a structural requirement of the language or library to ensure type safety or proper initialization.
