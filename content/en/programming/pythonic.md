## Definition

Code that follows Python's style and uses the language's own features, so it reads naturally to Python developers.

## Where you hear it

Python code reviews and style discussions.

## Examples

- A list comprehension is more Pythonic than a manual loop here.
- That works, but it is not very Pythonic.

## Common mistake

Squeezing everything into one clever line. Pythonic means readable, not shortest.
