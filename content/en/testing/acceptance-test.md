## Definition

A formal test performed to verify that a system meets the business requirements and is ready for delivery. It ensures the software functions according to the user's needs before it is officially accepted.

## Where you hear it

During sprint reviews, project handoffs, or when discussing the final sign-off criteria with stakeholders.

## Examples

- We need to run the acceptance tests before deploying to production.
- The user story is not complete until it passes the acceptance test.

## Common mistake

Confusing acceptance tests with unit tests; while unit tests check if individual code components work, acceptance tests focus on whether the entire feature fulfills the business goal.
