## Definition

Finding why code behaves wrongly and fixing it, using tools like logs, breakpoints, and careful reading.

## Where you hear it

Every developer's daily life.

## Examples

- I spent two hours debugging a missing comma.
- Add a breakpoint and debug it step by step.

## Common mistake

Changing random things hoping it works. First reproduce the bug, then form a theory, then test it.
