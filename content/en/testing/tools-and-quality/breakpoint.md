## Definition

A marker set on a line of code that pauses the program when it reaches that line, so a developer can inspect variables and step through the code.

## Where you hear it

In debuggers, IDEs, and when a developer says "put a breakpoint there".

## Examples

- Set a breakpoint on the line where the total becomes negative.
- The breakpoint only stops when the user id is 42.
- Add a breakpoint inside the loop to see why the counter stops early.

## Common mistake

Leaving breakpoints in the code and committing them. They can freeze a server that runs the code.

## Don't confuse with

A breakpoint pauses a program for inspection. A log message records information and lets the program keep running.
