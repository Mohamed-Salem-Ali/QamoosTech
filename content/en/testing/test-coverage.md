## Definition

The percentage of your code that runs during tests. It shows what is untested, but not how good the tests are.

## Where you hear it

Quality gates and code review rules.

## Examples

- Test coverage is 82%, but the payment module is not covered.
- We require at least 80% coverage on new code.

## Common mistake

Chasing 100% coverage with meaningless tests. A high number does not prove the code is correct.
