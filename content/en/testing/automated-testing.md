## Definition

Using software tools and scripts to run tests on code automatically, rather than testing features manually.

## Where you hear it

- In CI/CD pipelines
- During pull request reviews
- In QA and release planning meetings

## Examples

- We added automated testing to check our payment flow on every commit.
- Automated testing helps us catch regressions before code reaches production.

## Common mistake

Thinking that automated testing replaces manual testing entirely, rather than complementing it by handling repetitive checks.
