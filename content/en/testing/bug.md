## Definition

A mistake in the code that makes the software behave in a wrong or unexpected way.

## Where you hear it

Daily work, bug trackers, and client messages.

## Examples

- I found a bug in the checkout page.
- Please include steps to reproduce the bug.

## Common mistake

Reporting "it does not work" without details. Always add steps, expected result, and actual result.
