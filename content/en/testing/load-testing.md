## Definition

Load testing is a performance testing process that simulates real-world user demand on a software system to measure its behavior under expected and peak conditions. It ensures the application remains stable and responsive when many users access it simultaneously.

## Where you hear it

During sprint planning, infrastructure discussions, or when preparing for a major product release.

## Examples

- We need to perform load testing before the holiday season to ensure our servers don't crash.
- The team ran a load test to see how many concurrent users the new API endpoint can handle.

## Common mistake

Confusing load testing with stress testing; while load testing checks performance under expected limits, stress testing pushes the system beyond its limits to see how and when it fails.
