## Definition

A collection of test cases grouped together to be executed on a software program to verify that it behaves as expected.

## Where you hear it

In CI/CD pipelines, code reviews, and when discussing overall application quality.

## Examples

- The continuous integration pipeline runs the entire test suite on every pull request.
- Developers run a fast unit test suite locally before pushing their changes.

## Common mistake

Treating a test suite as a single test case instead of a collection of multiple tests.
