## التعريف

نظام منظّم لتخزين البيانات، يتيح للبرامج حفظها والبحث فيها وتحديثها بشكل موثوق.

## أين تسمعه؟

كل مشروع backend وكل إعلان وظيفة.

## أمثلة

- We store users and orders in a PostgreSQL database.
  - نخزّن المستخدمين والطلبات في قاعدة بيانات PostgreSQL.
- The database is down, so the app cannot log anyone in.
  - قاعدة البيانات متوقفة، لذلك لا يستطيع التطبيق تسجيل دخول أحد.

## خطأ شائع

التعامل مع قاعدة البيانات كمكان للملفات المؤقتة. هي للبيانات المنظمة التي تحتاج إلى الاستعلام عنها.

## لا تخلطه مع

الفرق بين قاعدة البيانات (Database) ونظام إدارة قواعد البيانات (DBMS) هو أن قاعدة البيانات هي مجموعة البيانات المنظمة نفسها، بينما نظام الإدارة هو البرنامج المستخدم للتحكم في هذه البيانات والوصول إليها.

## قلها في العمل

- I need to check the database to see if the user's record was created correctly.
  - أحتاج إلى التحقق من قاعدة البيانات لمعرفة ما إذا تم إنشاء سجل المستخدم بشكل صحيح.
- Please ensure that the migration script updates the database schema without causing any downtime.
  - يرجى التأكد من أن سكربت الترحيل يقوم بتحديث مخطط قاعدة البيانات دون التسبب في أي توقف للنظام.
