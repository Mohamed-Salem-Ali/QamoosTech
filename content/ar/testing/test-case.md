## التعريف

هو مجموعة من الشروط والمدخلات والنتائج المتوقعة التي تُستخدم للتحقق من أن ميزة معينة في النظام تعمل بشكل صحيح. يُعتبر بمثابة دليل للمختبرين للتأكد من أداء البرنامج.

## أين تسمعه؟

في اجتماعات ضمان الجودة (QA)، عند كتابة تقارير الأخطاء، وفي وثائق الاختبار.

## أمثلة

- We need to write a new test case for the password reset functionality.
  - نحتاج لكتابة Test Case جديدة لوظيفة إعادة تعيين كلمة المرور.
- This test case failed because the system returned an error instead of the expected success message.
  - فشلت هذه الـ Test Case لأن النظام أعاد خطأً بدلاً من رسالة النجاح المتوقعة.

## خطأ شائع

الخلط بين الـ Test Case وخطة الاختبار (Test Plan)؛ فالـ Test Case هي خطوة تحقق دقيقة ومحددة، بينما خطة الاختبار هي وثيقة شاملة تغطي استراتيجية الاختبار بالكامل.
