## التعريف

إجراء محادثة قصيرة غير رسمية لتبادل المستجدات أو للتأكد أن كل شيء بخير.

## أين تسمعه؟

الاجتماعات واللقاءات الدورية مع المدير أو العميل.

## أمثلة

- Let's touch base on Thursday about the release.
  - لنتواصل يوم الخميس بشأن الإصدار.
- I wanted to touch base before the deadline.
  - أردتُ أن أتواصل معك قبل الموعد النهائي.

## خطأ شائع

استخدامها وأنت تريد شيئًا محددًا. إذا كنت تحتاج شيئًا فاطلبه مباشرة.

## لا تخلطه مع

غالباً ما يتم الخلط بين touch base و sync up، ولكن بينما يعني touch base إجراء فحص سريع أو تحديث للحالة، يشير sync up عادةً إلى التوافق حول تفاصيل تقنية محددة أو متطلبات المشروع.

## قلها في العمل

- Do you have a minute to touch base about the new API documentation?
  - هل لديك دقيقة لنتواصل سريعاً بشأن وثائق الـ API الجديدة؟
- I would like to touch base regarding the progress of the current sprint before our weekly meeting.
  - أود التواصل معكم بخصوص تقدم الـ sprint الحالي قبل اجتماعنا الأسبوعي.
