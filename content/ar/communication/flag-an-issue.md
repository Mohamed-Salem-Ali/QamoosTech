## التعريف

الإشارة إلى وجود مشكلة محتملة أو خطر يتطلب انتباه الفريق. هي وسيلة استباقية للتنبيه حول أمر قد يعيق سير العمل أو المشروع.

## أين تسمعه؟

في اجتماعات المتابعة اليومية، أو عبر أدوات إدارة المشاريع، أو في قنوات التواصل بين أعضاء الفريق.

## أمثلة

- Please flag an issue if you notice any discrepancies in the documentation.
  - يرجى التنبيه إلى أي مشكلة إذا لاحظت وجود تعارض في الوثائق.
- I need to flag an issue regarding the current API response time.
  - أحتاج إلى التنبيه إلى مشكلة بخصوص وقت استجابة الـ API الحالي.
- I flagged an issue: the vendor's API limit may block the launch.
  - نبّهت إلى مشكلة محتملة: قد يعطّل حدّ استخدام واجهة المورد الإطلاق.

## خطأ شائع

الاعتقاد بأن "Flag an issue" تعني التذمر أو الشكوى؛ الهدف منها هو التنبيه بشكل بناء لحل المشكلة في وقت مبكر قبل تفاقمها.

## لا تخلطه مع

يُخلط أحياناً بين التنبيه إلى مشكلة (flagging) والإبلاغ عن خلل برمجي (bug report)؛ فالتنبيه إلى مشكلة هو تنبيه استباقي لخطر محتمل، بينما الإبلاغ عن خلل هو توثيق رسمي لخطأ مؤكد في النظام.

## قلها في العمل

- I'm going to flag an issue with the database migration plan since we might hit some performance bottlenecks.
  - سأقوم بالتنبيه إلى مشكلة في خطة ترحيل قاعدة البيانات لأننا قد نواجه بعض الاختناقات في الأداء.
- I would like to flag an issue regarding the upcoming deadline, as the current resource allocation appears insufficient to meet our requirements.
  - أود التنبيه إلى مشكلة تتعلق بالموعد النهائي القادم، حيث يبدو أن تخصيص الموارد الحالي غير كافٍ لتلبية متطلباتنا.
