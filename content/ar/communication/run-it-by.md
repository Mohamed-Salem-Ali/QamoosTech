## التعريف

مشاركة فكرة أو تصميم أو خطة مع شخص ما للحصول على ملاحظاته أو رأيه أو موافقته قبل اتخاذ أي خطوة.

## أين تسمعه؟

في اجتماعات الفريق، أو قنوات المحادثة، أو النقاشات السريعة قبل دمج الكود أو تغيير هيكلية النظام.

## أمثلة

- Let me run this database migration plan by the senior engineer before we apply it.
  - دعني أعرض خطة ترحيل قواعد البيانات هذه على المهندس الأول قبل أن نطبقها.
- I have a new caching strategy, but I want to run it by the team lead first.
  - لدي استراتيجية تخزين مؤقت جديدة، لكني أريد أن أستشير قائد الفريق أولاً.

## خطأ شائع

الاعتقاد بأنها تعني طلب الإذن لكل صغيرة وكبيرة، بينما هي غالباً مجرد مراجعة سريعة لمنع حدوث مشكلات غير متوقعة.
