## التعريف

قيمة تجمع بيانات مترابطة (خصائص) وأحيانًا سلوكًا (دوال) تحت اسم واحد.

## أين تسمعه؟

أساسيات JavaScript وPython، وبيانات JSON، والبرمجة كائنية التوجّه.

## أمثلة

- Send the user as a JSON object with `name` and `email`.
  - أرسل المستخدم ككائن JSON فيه `name` و `email`.
- Each `Order` object has a `total` property.
  - كل كائن `Order` له خاصية `total`.

## خطأ شائع

الخلط بين «object» (نسخة فيها بيانات حقيقية) و«class» (المخطط الذي تُبنى منه).
