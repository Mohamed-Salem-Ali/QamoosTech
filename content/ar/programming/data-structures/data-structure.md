## التعريف

هيكل البيانات (Data Structure) طريقة لتنظيم البيانات في الذاكرة لاستخدامها بكفاءة، مثل القائمة والقاموس والمجموعة والشجرة.

## أين تسمعه؟

في مقررات علوم الحاسوب، ومقابلات البرمجة، ونقاشات الأداء حول الاختيار بين قائمة وقاموس.

## أمثلة

- Choosing the right data structure turned a slow search into an instant lookup.
  - اختيار هيكل البيانات المناسب حوّل بحثاً بطيئاً إلى وصول فوري.
- A set is the best data structure for checking membership quickly.
  - المجموعة (set) هي أفضل هيكل بيانات للتحقق السريع من الانتماء.
- A hash table is a data structure that gives fast lookups by key.
  - جدول التجزئة (hash table) بنية بيانات تتيح البحث السريع بالمفتاح.

## خطأ شائع

اختيار الهيكل بالعادة. لكل هيكل عمليات سريعة وأخرى بطيئة، لذا اختر بحسب طريقة استخدامك للبيانات.

## لا تخلطه مع

الخوارزمية (Algorithm) وهي خطوات معالجة البيانات. أما هيكل البيانات فهو طريقة ترتيبها.

## قلها في العمل

- A dictionary is a better data structure than a list for this lookup.
  - القاموس هيكل بيانات أفضل من القائمة لهذا البحث.
- Let's pick the data structure before writing the loop.
  - لنختر هيكل البيانات قبل كتابة الحلقة.
