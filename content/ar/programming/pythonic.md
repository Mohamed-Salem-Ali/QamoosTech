## التعريف

شيفرة تتبع أسلوب Python وتستفيد من إمكانيات اللغة نفسها، فيقرأها مبرمجو Python بسهولة.

## أين تسمعه؟

مراجعة شيفرة Python والنقاش حول الأسلوب.

## أمثلة

- A list comprehension is more Pythonic than a manual loop here.
  - استخدام list comprehension أكثر بايثونية من الحلقة اليدوية هنا.
- That works, but it is not very Pythonic.
  - هذا يعمل، لكنه ليس بايثونيًا جدًا.

## خطأ شائع

حشر كل شيء في سطر واحد «ذكي». المقصود بالبايثوني أن يكون مقروءًا لا أقصر.
