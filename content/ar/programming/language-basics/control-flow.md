## التعريف

تدفق التحكم (Control Flow) هو الترتيب الذي تُنفَّذ به أوامر البرنامج، وتحدده الشروط والحلقات واستدعاءات الدوال.

## أين تسمعه؟

في دورات البرمجة للمبتدئين، ومراجعات الكود التي تبسّط الشروط المتداخلة، وجلسات تصحيح الأخطاء التي تتبع ما نُفِّذ.

## أمثلة

- The control flow is hard to follow because of so many nested conditions.
  - من الصعب تتبع تدفق التحكم بسبب كثرة الشروط المتداخلة.
- An early return simplifies the control flow.
  - الإرجاع المبكر يبسّط تدفق التحكم.
- A break inside the loop changes the control flow, so the code after the loop runs next.
  - تغيّر عبارة break داخل الحلقة مسار التنفيذ، فيُنفَّذ الكود الذي بعد الحلقة مباشرة.

## خطأ شائع

تداخل الشروط عدة مستويات. أرجع مبكراً أو قسّم الكود إلى دوال صغيرة لتبقى الصورة مسطحة.

## لا تخلطه مع

تدفق البيانات (Data Flow) وهو كيف تنتقل القيم بين الدوال، وليس ترتيب تنفيذ الكود.

## قلها في العمل

- Let's flatten the control flow with guard clauses.
  - لنسطّح تدفق التحكم باستخدام guard clauses.
- Walk me through the control flow when the request fails.
  - اشرح لي تدفق التحكم عندما يفشل الطلب.
