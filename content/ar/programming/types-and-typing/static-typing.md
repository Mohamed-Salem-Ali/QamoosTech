## التعريف

التنميط الثابت (Static Typing) يعني أن الأنواع معروفة وتُفحص قبل تشغيل البرنامج، عادة عند ترجمة الكود أو تحليله.

## أين تسمعه؟

عند المقارنة بين لغات مثل Java وTypeScript وبين بايثون وجافاسكريبت، وفي الجدالات حول الأمان مقابل سرعة الكتابة.

## أمثلة

- Static typing caught the wrong argument before we deployed.
  - التنميط الثابت اكتشف الوسيط الخاطئ قبل النشر.
- TypeScript adds static typing on top of JavaScript.
  - تضيف TypeScript التنميط الثابت فوق جافاسكريبت.

## خطأ شائع

الظن بأن التنميط الثابت يعني عدم وجود أخطاء. هو يكتشف فئة من الأخطاء، لكن أخطاء المنطق تحتاج اختبارات.

## لا تخلطه مع

التنميط الديناميكي حيث يخص النوع القيمة ويُفحص أثناء تشغيل البرنامج.

## قلها في العمل

- Static typing would have caught this at build time.
  - كان التنميط الثابت سيكتشف هذا وقت البناء.
- We chose a statically typed language for the core service.
  - اخترنا لغة ثابتة التنميط للخدمة الأساسية.
