## التعريف

ISO 8601 هو المعيار الدولي لكتابة التواريخ والأوقات كنص، مثل `2026-10-10` أو `2026-10-10T18:30:00Z`.

## أين تسمعه؟

في توثيق الـ API، وتصدير قواعد البيانات، وأي نقاش حول كيف تنتقل التواريخ بين الأنظمة.

## أمثلة

- The API returns every date in ISO 8601 format.
  - يعيد الـ API كل تاريخ بصيغة ISO 8601.
- ISO dates sort correctly as plain text.
  - تواريخ ISO تُرتَّب بشكل صحيح كنص عادي.
- The timestamp 2026-10-10T18:30:00Z uses ISO 8601, so every client parses it the same way.
  - الطابع الزمني 2026-10-10T18:30:00Z بصيغة ISO 8601، فيقرؤه كل عميل بالطريقة نفسها.

## خطأ شائع

إرسال التواريخ بصيغة `10/11/2026`. غير واضح هل هو 10 نوفمبر أم 11 أكتوبر.

## لا تخلطه مع

الطابع الزمني Unix وهو عدد من الثواني. أما ISO 8601 فنص مقروء.

## قلها في العمل

- Send dates in ISO format and convert them only for display.
  - أرسل التواريخ بصيغة ISO وحوّلها فقط عند العرض.
- Please include the time zone in the ISO string.
  - من فضلك أضف المنطقة الزمنية إلى نص ISO.
