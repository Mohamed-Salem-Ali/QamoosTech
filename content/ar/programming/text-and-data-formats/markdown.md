## التعريف

صيغة نص عادي تستخدم علامات خفيفة للبنية. السطر الذي يبدأ بـ # عنوان، والشرطة تبدأ عنصر قائمة، والنجمتان تُبرزان الكلمة. وتحوّلها الأدوات إلى HTML للعرض.

## أين تسمعه؟

في ملفات README، وأوصاف طلبات الدمج، ومواقع التوثيق، وتطبيقات المحادثة.

## أمثلة

- Write the setup steps in Markdown so they show as a numbered list on GitHub.
  - اكتب خطوات التثبيت بصيغة Markdown لتظهر قائمة مرقّمة على GitHub.
- Wrap a command in backticks to show it as code.
  - ضع الأمر بين علامتي الاقتباس العكسيتين ليظهر كشيفرة.
- The docs site turns the Markdown files into web pages when it builds.
  - يحوّل موقع التوثيق ملفات Markdown إلى صفحات ويب عند البناء.

## خطأ شائع

توقّع أنه سيبدو متطابقاً في كل مكان. تدعم كل أداة إضافات مختلفة مثل الجداول، فاختبره في المكان الذي سيُقرأ فيه.

## لا تخلطه مع

HTML هو ما يعرضه المتصفح، وكتابته يدوياً أطول بكثير. أما Markdown فهو المصدر الذي يكتبه الناس، ثم تُنتج أداة HTML منه.

## قلها في العمل

- Can you put the reproduction steps in Markdown in the ticket?
  - هل تكتب خطوات إعادة الخطأ بصيغة Markdown في التذكرة؟
- The table does not render in our old wiki; can we use a list instead?
  - الجدول لا يظهر في ويكينا القديمة؛ هل نستخدم قائمة بدلاً منه؟
