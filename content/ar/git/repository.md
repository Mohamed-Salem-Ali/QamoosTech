## التعريف

مجلد يتتبعه Git ويحتوي على ملفات المشروع وتاريخ تغييراتها كاملًا. يُختصر غالبًا إلى «repo».

## أين تسمعه؟

في كل فريق: «استنسخ الـ repo»، «افتح الـ repo».

## أمثلة

- Clone the repository and run `npm install`.
  - استنسخ المستودع ثم شغّل `npm install`.
- The repo is private, so ask for access.
  - المستودع خاص، لذلك اطلب صلاحية الوصول.

## خطأ شائع

رفع ملفات كبيرة وأسرار. بعد دخولها التاريخ يصعب حذفها تمامًا.
