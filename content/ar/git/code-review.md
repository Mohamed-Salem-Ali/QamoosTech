## التعريف

عندما يقرأ زملاؤك تغييراتك قبل دمجها، لاكتشاف الأخطاء وتحسين الجودة ومشاركة المعرفة.

## أين تسمعه؟

كل فريق محترف.

## أمثلة

- Can you review my pull request today?
  - هل تستطيع مراجعة الـ pull request الخاص بي اليوم؟
- The code review caught a security bug.
  - اكتشفت مراجعة الشيفرة ثغرة أمنية.

## خطأ شائع

كتابة تعليقات حادة مثل «هذا خطأ». اشرح السبب واقترح طريقة أفضل.
