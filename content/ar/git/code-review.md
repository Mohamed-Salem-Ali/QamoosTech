## التعريف

عندما يقرأ زملاؤك تغييراتك قبل دمجها، لاكتشاف الأخطاء وتحسين الجودة ومشاركة المعرفة.

## أين تسمعه؟

كل فريق محترف.

## أمثلة

- Can you review my pull request today?
  - هل تستطيع مراجعة الـ pull request الخاص بي اليوم؟
- The code review caught a security bug.
  - اكتشفت مراجعة الشيفرة ثغرة أمنية.

## خطأ شائع

كتابة تعليقات حادة مثل «هذا خطأ». اشرح السبب واقترح طريقة أفضل.

## لا تخلطه مع

غالباً ما يتم الخلط بين مراجعة الشيفرة والبرمجة الثنائية؛ فبينما تحدث مراجعة الشيفرة بشكل غير متزامن بعد كتابة الكود، تتضمن البرمجة الثنائية عمل مطورين على نفس المهمة في وقت واحد وبشكل مباشر.

## قلها في العمل

- I've pushed the updates, could you please take a look at the code review when you have a moment?
  - لقد قمت برفع التحديثات، هل يمكنك إلقاء نظرة على مراجعة الشيفرة عندما يتسنى لك ذلك؟
- Please address the feedback provided in the code review before we proceed with merging this branch.
  - يرجى معالجة الملاحظات الواردة في مراجعة الشيفرة قبل أن نتابع عملية دمج هذا الفرع.
