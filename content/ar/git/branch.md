## التعريف

خط عمل منفصل في Git، يتيح لك بناء ميزة دون التأثير في الشيفرة الرئيسية.

## أين تسمعه؟

سير عمل الفرق («أنشئ branch للمهمة»).

## أمثلة

- Create a new branch for the payment feature.
  - أنشئ branch جديدًا لميزة الدفع.
- Do not push directly to the `main` branch.
  - لا تعمل push مباشرةً إلى فرع `main`.

## خطأ شائع

إبقاء الفرع حيًا لأسابيع. كلما طالت مدته صعب دمجه.
