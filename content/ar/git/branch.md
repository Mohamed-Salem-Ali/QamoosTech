## التعريف

خط عمل منفصل في Git، يتيح لك بناء ميزة دون التأثير في الشيفرة الرئيسية.

## أين تسمعه؟

سير عمل الفرق («أنشئ branch للمهمة»).

## أمثلة

- Create a new branch for the payment feature.
  - أنشئ branch جديدًا لميزة الدفع.
- Do not push directly to the `main` branch.
  - لا تعمل push مباشرةً إلى فرع `main`.
- Rebase the feature branch on main before you open the pull request.
  - أعِد تأسيس فرع الميزة على main قبل أن تفتح طلب الدمج.

## خطأ شائع

إبقاء الفرع حيًا لأسابيع. كلما طالت مدته صعب دمجه.

## قلها في العمل

- Can you please push your branch to the remote repository so I can review it?
  - هل يمكنك من فضلك رفع الـ branch الخاص بك إلى المستودع البعيد لكي أتمكن من مراجعته؟
- I created a new branch from main to fix the login bug.
  - أنشأت فرعًا جديدًا من main لإصلاح مشكلة تسجيل الدخول.
