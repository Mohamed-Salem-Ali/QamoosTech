## التعريف

طلب لدمج فرعك في فرع آخر، يستطيع فيه زملاؤك مراجعة التغييرات والتعليق عليها قبل قبولها.

## أين تسمعه؟

العمل اليومي في الفريق على GitHub وGitLab.

## أمثلة

- I opened a pull request for the login fix.
  - فتحتُ pull request لإصلاح تسجيل الدخول.
- Please keep the PR small so it is easy to review.
  - من فضلك اجعل الـ PR صغيرًا ليسهل مراجعته.

## خطأ شائع

فتح PRs ضخمة بتغييرات كثيرة غير مترابطة. الـ PRs الصغيرة المركّزة تحظى بمراجعة أفضل.
