## التعريف

فترة قبل الإصدار لا يُدمج فيها أي تغيير جديد، إلا الإصلاحات المعتمدة لذلك الإصدار. وهي تمنح الفريق وقتاً لاختبار ما سيُطلق.

## أين تسمعه؟

قبل إطلاق كبير، وفي تقويمات الإصدارات، وفي رسائل مثل: «نحن في فترة تجميد الشيفرة».

## أمثلة

- We are in code freeze from Wednesday until the release.
  - نحن في فترة تجميد الشيفرة من يوم الأربعاء حتى الإصدار.
- Only security fixes are allowed during the code freeze.
  - لا يُسمح إلا بإصلاحات الأمان خلال فترة تجميد الشيفرة.
- The code freeze starts Thursday, and only approved fixes can be merged after that.
  - يبدأ تجميد الشيفرة يوم الخميس، ولا يُدمج بعده إلا الإصلاحات المعتمدة.

## خطأ شائع

تجميد الشيفرة دون تاريخ انتهاء واضح أو قائمة بالتغييرات المسموحة، فيتوقف الفريق دون سبب واضح.

## لا تخلطه مع

تجميد الشيفرة يمنع التغييرات الجديدة قبل الإصدار، أما تجميد الميزات فيمنع الميزات الجديدة فقط ويسمح بالإصلاحات.
