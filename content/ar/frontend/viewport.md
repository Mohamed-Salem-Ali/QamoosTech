## التعريف

المساحة المرئية من صفحة الويب داخل نافذة المتصفح أو على شاشة الهاتف.

## أين تسمعه؟

CSS (`vw` و`vh`)، وmedia queries، واختبار الجوال.

## أمثلة

- The menu should collapse when the viewport is narrower than 600px.
  - يجب أن تنطوي القائمة عندما يكون عرض الـ viewport أقل من 600 بكسل.
- Add the viewport meta tag, or the page will look tiny on phones.
  - أضف وسم viewport وإلا ستبدو الصفحة صغيرة جدًا على الهواتف.

## خطأ شائع

الخلط بين الـ viewport والصفحة كاملة. قد تكون الصفحة أطول بكثير من الـ viewport.

## لا تخلطه مع

يشير الـ viewport إلى المساحة المرئية من نافذة المتصفح، بينما تشير الـ screen إلى الأبعاد المادية للشاشة أو جهاز الجوال.

## قلها في العمل

- Let us test this component across different viewport sizes to ensure the layout does not break.
  - دعنا نختبر هذا المكون عبر مقاسات viewport مختلفة لضمان عدم تعطل التنسيق.
- Please update the media query so it triggers when the viewport width drops below 768px.
  - يرجى تحديث الـ media query لكي تعمل عندما ينخفض عرض الـ viewport إلى أقل من 768 بكسل.
