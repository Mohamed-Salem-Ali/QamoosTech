## التعريف

نظام تخطيط ثنائي الأبعاد في CSS يسمح بترتيب العناصر في صفوف وأعمدة في آن واحد. يوفر هذا النظام وسيلة قوية لإنشاء تخطيطات معقدة لصفحات الويب بأقل قدر من الكود.

## أين تسمعه؟

أثناء اجتماعات تطوير الواجهات الأمامية، أو عند مراجعة الكود، أو عند مناقشة تنفيذ التصاميم المتجاوبة.

## أمثلة

- We should use CSS Grid to structure the main dashboard layout.
  - يجب أن نستخدم CSS Grid لهيكلة تخطيط لوحة التحكم الرئيسية.
- The new photo gallery uses CSS Grid to maintain a perfect alignment across different screen sizes.
  - معرض الصور الجديد يستخدم CSS Grid للحفاظ على محاذاة مثالية عبر أحجام الشاشات المختلفة.

## خطأ شائع

الاعتقاد بأن CSS Grid هو بديل لـ Flexbox؛ في الواقع، يكمل كلاهما الآخر، حيث يُستخدم Grid لهيكلة الصفحة ككل، بينما يُستخدم Flexbox لمحاذاة العناصر داخل المكونات الصغيرة.
