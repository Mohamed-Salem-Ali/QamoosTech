## التعريف

هو نموذج تخطيط في CSS مصمم لتوزيع المساحات ومحاذاة العناصر داخل حاوية معينة، حتى لو كانت أبعادها غير معروفة أو متغيرة. يتيح هذا النموذج ترتيب العناصر بسهولة في صف واحد أو عمود واحد.

## أين تسمعه؟

أثناء اجتماعات تطوير الواجهات الأمامية، أو عند مناقشة تنسيقات CSS، أو عند بناء تصميمات متجاوبة.

## أمثلة

- Use Flexbox to center a button inside a navigation bar.
  - استخدم Flexbox لتوسيط زر داخل شريط التنقل.
- We switched from floats to Flexbox to make the layout more responsive.
  - انتقلنا من استخدام floats إلى Flexbox لجعل التصميم أكثر تجاوباً.

## خطأ شائع

استخدام Flexbox لتصميم تخطيطات معقدة ثنائية الأبعاد، حيث يكون CSS Grid هو الأداة الأنسب والأكثر كفاءة لهذا الغرض.
