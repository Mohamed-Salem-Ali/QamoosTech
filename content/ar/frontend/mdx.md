## التعريف

صيغة Markdown تتيح استخدام مكوّنات JSX داخل ملف Markdown. وتشيع في مواقع التوثيق، حيث تعرض الصفحة مثالاً تفاعلياً إلى جانب النص العادي.

## أين تسمعه؟

مواقع التوثيق، والمدونات، ومنصات التعلّم.

## أمثلة

- Each lesson is an MDX file with a few custom components.
  - كل درس هو ملف MDX فيه بضعة مكوّنات مخصصة.
- Use plain Markdown unless you really need a component.
  - استخدم Markdown العادي ما لم تكن تحتاج مكوّنًا فعلًا.

## خطأ شائع

وضع منطق كثير في ملفات MDX. اجعل المحتوى بسيطًا والمنطق في المكوّنات.

## لا تخلطه مع

غالبًا ما يتم الخلط بين MDX وMarkdown العادي، ولكن بينما يدعم Markdown تنسيق النصوص الثابتة فقط، يسمح MDX بدمج مكوّنات React التفاعلية.
