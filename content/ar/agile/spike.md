## التعريف

مهمة محددة بزمن مخصص للبحث أو التصميم أو بناء نموذج أولى للإجابة على سؤال تقني قبل تقدير حجم العمل الحقيقي.

## أين تسمعه؟

في اجتماعات التخطيط للسبرنت، أو جلسات ترتيب الباكلوج، أو عند مواجهة تحدٍ تقني غير معروف.

## أمثلة

- We need a two-day spike to figure out which third-party payment gateway fits our security requirements.
  - نحتاج إلى مهمة بحثية لمدة يومين لنكتشف بوابة الدفع الخارجية التي تناسب متطلبات الأمان الخاصة بنا.
- Let us create a spike ticket to test if this database migration tool handles our table size.
  - دعنا ننشئ تذكرة بحثية لنختبر ما إذا كانت أداة نقل قاعدة البيانات هذه تتحمل حجم جداولنا.

## خطأ شائع

التعامل مع المهمة البحثية كأنها مشروع بحث مفتوح بدون حد زمنّي واضح أو هدف إخراج محدد.
